Exemplos de links no HTML5

Links são criados com a tag <a>. O destino é informado no atributo href.

Ir direto para um exemplo:
  • Link externo
  • Link interno
  • Link relativo
  • E-mail e telefone
  • Download
  • Imagem como link

1. Link para outro site

Use um endereço completo, começando com https://.

Documentação da tag <a> na MDN

Para abrir em outra aba, use target="_blank" junto com rel="noopener noreferrer":

Abrir a documentação em outra aba

2. Link para outra parte da mesma página

O valor de href começa com # e corresponde ao id do elemento de destino. Experimente ir até o exemplo de download.

3. Link para outra página do projeto

Um caminho relativo aponta para um arquivo a partir da localização desta página. Como este arquivo está na mesma pasta, podemos abrir a página de imagens:
